# Win-Tweaker 使用教程

**作者：微信号：zxzvsdcj**  
**软件：Win-Tweaker 系统优化工具 v1.0.0**

本软件支持按客户需求做功能定制（增删模块、调整默认策略、企业专属配置）。定制请微信联系：zxzvsdcj。

---

## 一、选哪个版本？

| 版本 | 适用场景 | 说明 |
|------|----------|------|
| **轻量版** | 电脑已安装 .NET 9 Desktop Runtime x64 | 体积小（约数 MB） |
| **完整版** | 不确定是否有 .NET、或想开箱即用 | 自带运行库，双击即可（体积较大） |

若轻量版启动报错缺少 .NET / 运行库，请改用完整版，或安装官方 [.NET 9 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/9.0)。

---

## 二、安装与启动

1. 解压收到的压缩包到任意目录（建议路径不含中文空格问题较少的位置亦可）。
2. 确认同目录下有 `WinTweaker.exe`。授权凭证已编进程序，目录里不需要、也不应出现额外的配置文件。
3. 右键 `WinTweaker.exe` → **以管理员身份运行**（必须管理员，否则无法改系统设置）。
4. 首次可能弹出 UAC，请选择「是」。

---

## 三、授权激活

1. 若弹出「授权激活」窗口，界面会显示本机 **机器码**。
2. 将机器码发给作者微信 **zxzvsdcj**，完成登记后重新打开软件。
3. 联网校验成功后，功能解锁；离线时可能有最长约 7 天的缓存宽限（需曾成功在线激活过）。

激活失败时请检查：网络、机器码是否复制完整、是否使用了对应产品的安装包。

## 四、界面说明

左侧导航：

| 菜单 | 作用 |
|------|------|
| 常规优化 | 电源、遥测、广告、服务、资源管理器、内存完整性（HVCI）、WSL 等日常优化 |
| 更新管理 | 禁止 Edge / Chrome 自动更新 |
| Win11 专属 | 仅 Windows 11 可用的体验与隐私项 |
| 高危操作 | UAC / 防火墙 / Defender / Windows Update（慎用） |
| 帮助 | 软件内详细说明与操作指引（推荐先看） |
| 日志 | 操作结果与错误信息 |

顶部标题栏会显示当前系统版本信息。灰色开关 = 当前系统不支持，属正常。

**基本操作：** 打开开关 = 应用优化；关闭开关 = 回滚。多数操作可逆。

## 五、功能介绍与操作指引

### 5.1 常规优化

| 功能 | 做什么 | 操作提示 |
|------|--------|----------|
| 卓越性能电源计划 | 启用 Ultimate Performance | 适合高性能场景 |
| 系统遥测降级 | 诊断数据降为基础级 | 减少后台上传 |
| 关闭系统广告 | 关锁屏/开始菜单等广告 | 建议开启 |
| 裁剪冗余服务 | 禁 DiagTrack、Xbox、SysMain 等 | 回滚会恢复原启动类型 |
| 全局禁止后台运行 | 阻止 UWP 后台耗资源 | 部分商店应用推送会受影响 |
| 关闭休眠 | 删 hiberfil.sys 释放大文件 | 仍可用睡眠；笔记本需注意 |
| 资源管理器优化 | 关云广告、显示系统文件 | — |
| 始终显示文件扩展名 | 防伪装脚本 | 开发机强烈建议开 |
| 禁用保留存储 | 释放系统预留空间 | 大更新前建议重新开启 |
| 内存完整性（HVCI） | Hypervisor 内核防护；关闭可释放 VT-x/AMD-V 给虚拟机软件 | 开关有确认；改后需**重启电脑**；状态分「运行中 / 已关闭 / 待重启」；BIOS 未开虚拟化时置灰 |
| WSL2 高性能配置 | 生成 `.wslconfig` | 点「生成配置」按钮 |

### 5.2 更新管理

| 功能 | 做什么 | 操作提示 |
|------|--------|----------|
| 禁止 Edge 自动更新 | 策略 + 服务禁用 | About 可能显示「由组织管理」 |
| 禁止 Chrome 自动更新 | 策略（32/64 位）+ 服务 | 需新版本时手动装官方包或关开关 |

| 禁用 Snap 悬停提示 | 关最大化 Snap 弹出 | — |
| 关闭开始菜单推荐广告 | 减少推荐干扰 | — |
| 文件夹悬停详细信息 | 悬停看大小与摘要 | — |
| 禁用搜索高亮 | 关搜索框动态内容 | — |
| 任务栏时钟显示秒 | 精确到秒 | — |

### 5.4 高危操作（二次确认 / 谨慎使用）

| 功能 | 风险 | 说明 |
|------|------|------|
| 关闭 UAC | 高 | 需重启生效 |
| 关闭防火墙 | 高 | 三个配置文件全关 |
| 压制 Defender | 高 | 家庭版可能受限 |
| 禁止 Windows 更新 | 高 | 不再自动安全补丁 |

页面提供 **「恢复全部」**：一键恢复本页相关高危项到操作前状态。

## 六、日志与排障

1. 打开「日志」查看每步结果：黑信息 / 绿成功 / 黄警告 / 红错误。
2. 「复制全部」可发给微信 zxzvsdcj 协助排查。
3. 常见问题：

| 现象 | 处理 |
|------|------|
| 轻量版无法启动 | 装 .NET 9 Desktop Runtime，或改用完整版 |
| 提示需要管理员 | 右键「以管理员身份运行」 |
| 开关是灰的 | 当前系统不支持，忽略即可 |
| 授权失败 | 核对机器码与网络，联系微信 |
| 改完没生效 | 看日志是否要求重启 Explorer / 注销 / 重启 |
| VMware/VirtualBox 闪退 | 尝试关闭「内存完整性（HVCI）」并重启电脑 |
| HVCI 开关是灰的 | BIOS 中开启 Intel VT-x / AMD-V 后再试 |

## 七、配置方案（导出 / 导入）

适合：保存自己的开关组合、下次一键恢复、把方案发给其他客户复用。

1. 打开软件「帮助」页 → **导出方案**，保存为 `.json` 文件。
2. 在另一台电脑（或本机重装后）打开「帮助」→ **导入方案**，选择该文件。
3. 导入后会立即应用；含高危项时会统一确认一次。

**版本兼容：**
- 新版多了功能、旧方案没有对应项 → 这些项保持现状
- 旧版读到新方案里的未知功能键 → 自动跳过并写日志，不中断
- 导入结束会显示：已应用 / 跳过未知 / 不支持 / 失败 数量

## 八、注意事项

- 所有常规优化均可回滚；高危项请确认用途后再动。
- 禁用 Windows Update 后请自行定期检查安全补丁。
- 禁用浏览器更新后需自行安装浏览器新版本。
- 授权凭证在程序内部，不要向他人索要或传播安装包以外的密钥文件。
