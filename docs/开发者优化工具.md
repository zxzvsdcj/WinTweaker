
# Win-Tweaker 全Win10/Win11系统优化工具

## 最终完整版PRD文档（支持双打包模式、全系统兼容、纯C#无PowerShell）

## 一、项目基础信息

### 1.1 项目名称

Win-Tweaker Windows全版本系统开发者优化工具

### 1.2 支持系统（全覆盖）

- Windows10：1903 / 1909 / 20H2 / 21H2 / 22H2（全部正式版）
- Windows11：21H2 / 22H2 / 23H2 / 24H2 / 25H2 Insider 预览版（26200.x）
- 拦截：Win7/Win8/Server系统，直接弹窗退出

### 1.3 技术栈

- 核心：**C# .NET 9 WPF**
- UI组件：**WPF-UI（FluentWindow、Mica/Acrylic自适应）**
- 实现方式：**纯原生C# API，零PowerShell、零CMD、零脚本依赖（模式B最终方案）**

### 1.4 运行权限

- 程序**强制管理员权限启动**（AppManifest固化）

### 1.5 核心原则

1. 全系统版本自适应，自动判断Win10/Win11、家庭版/专业版、预览版/正式版
2. 不支持的功能自动置灰、提示、不报错
3. 所有操作双向可逆（优化+回滚）
4. 全部状态开机自动扫描、UI实时同步
5. 完整彩色日志系统
6. **支持两种官方发布打包模式（可选输出）**

## 三、UI 视觉规范（Mica/Acrylic 全系统自适应）
### 3.1 Mica 云母窗口定义
Mica 是 **Win11专属系统级磨砂材质**
- 跟随桌面壁纸动态变色、模糊、半透明
- 和系统设置、文件资源管理器质感一致
- 仅 Win11 Build ≥ 22000 生效

### 3.2 自适应规则（代码自动判断）
- **如果检测 Win11**：`WindowBackdropType="Mica"` 云母效果
- **如果检测 Win10**：自动降级 `Acrylic` 亚克力，不报错、不空白

### 3.3 UI 全局规范
- 自动跟随系统深色/浅色模式
- 高信息密度布局、无大面积留白
- 卡片式分组、高危功能红色警示卡片
- 全部开关带悬浮Tooltip说明
- 不支持功能自动置灰 + 小字版本说明

## 四、完整功能列表（全系统兼容）
### 常规优化（全版本通用）
1. 新增卓越性能电源计划
2. WSL2 高性能 .wslconfig 自动生成
3. 系统遥测降级基础级别
4. 关闭系统全部广告、推荐、通知、同步提示
5. 裁剪冗余服务：DiagTrack、Xbox全套、SysMain
6. 全局禁止应用后台运行
7. 关闭休眠、释放C盘空间（保留睡眠）
8. 资源管理器关闭云广告、强制显示文件后缀
9. 阻止系统静默安装推荐应用、OEM预装
10. 关闭锁屏/开始菜单广告推送

### Win11 专属功能（Win10自动置灰）
1. 禁用 Copilot 后台常驻
2. 禁用 Widgets 小组件
3. 关闭任务栏必应搜索广告

### 高危优化（全版本通用、红色警示、二次确认）
1. 关闭 UAC 用户账户控制
2. 完全关闭 Windows 防火墙（域/专用/公用）
3. 策略压制 Defender 实时防护（自动适配新版Win11策略限制并日志提示）

## 五、核心业务架构（严格MVVM、纯C#无PS）
### 分层结构
1. **UI View**：WPF-UI FluentWindow 界面
2. **ViewModel**：状态绑定、命令、版本适配、控件可用性控制
3. **Service 核心服务层**
   - SystemInfoService（系统版本/SKU/预览版检测）
   - RegistryService
   - ServiceManager（**缓存原始服务启动类型，精准回滚**）
   - PowerPlanService
   - FirewallService
   - SystemSecurityService（UAC/Defender）
   - WslConfigService
   - TelemetryService
4. **Utils**：日志、弹窗、权限校验
5. **Model**：系统能力模型、优化项模型、日志模型

### 关键特色机制
1. **服务原始状态内存缓存**
   - 优化前读取服务原始启动类型存入字典
   - 回滚不硬编码，**100%还原系统初始状态**
2. **系统能力掩码**
   - 开机一次性判断所有功能可用性
   - UI全自动置灰、禁用、提示
3. **预览版特殊提示**
   - 检测25H2预览版 → 黄色日志提示：安全策略会被系统自动重置

## 六、日志系统规范
- 带时间戳
- 四色分级：黑(信息)、绿(成功)、黄(警告)、红(错误)
- 支持清空日志、复制全部日志
- 自动提示：版本不支持、家庭版策略无效、预览版重置风险

---

## 七、一键回滚机制（全对称可逆）
所有优化项**1:1对应回滚逻辑**
1. 恢复电源计划默认
2. 恢复Copilot/Widgets（Win11）
3. 恢复遥测默认
4. 恢复全部广告、通知、资源管理器设置
5. **按内存缓存恢复所有服务原始启动类型**
6. 恢复后台应用权限、休眠、搜索配置
7. 高危项回滚：开启UAC、全开防火墙、恢复Defender防护策略
